    Rapport annuel

    Identité du bureau

    Le nom et l'adresse du bureau : ils signent les messages envoyés, les feuilles imprimées et, si vous domiciliez, les attestations d'élection de domicile. Laissés vides, l'attestation s'imprime quand même, avec des traits à compléter à la main.

    Il apparaît dans les courriels, en tête des impressions et sur les attestations.

    C'est l'adresse que la personne domiciliée donnera aux administrations. Avec plusieurs antennes, celle de l'antenne du dossier est utilisée si elle est renseignée.

    Antennes (0)

    Plusieurs points d'accueil peuvent partager ce serveur. Chaque destinataire et chaque courrier appartient à une antenne ; le sélecteur en haut de page filtre tout l'écran. Un accès agent peut être limité à une seule antenne — il ne reçoit alors rien des autres. Tant qu'aucune antenne n'est déclarée, rien de tout cela n'apparaît.

    Postes du bureau

    Le registre vit sur ce poste. Les autres ordinateurs du bureau n'ont rien à installer : ils ouvrent l'adresse ci-dessous dans leur navigateur et travaillent sur le même registre, en même temps.

    Reliés en ce moment

    Message envoyé aux destinataires

    Utilisé pour l'envoi automatique. Laissé vide, c'est MAIL_FROM du serveur qui s'applique. Sans envoi automatique, l'expéditeur reste celui du logiciel de courriel.

    Modèle du message

    Le modèle général sert à tout le courrier. Chaque type peut recevoir son propre texte : un recommandé n'appelle pas la même phrase qu'un prospectus.

    La personne montre souvent son message à quelqu'un qui ne lit pas sa langue — un travailleur social, un autre guichet. Et l'agent qui l'envoie peut relire ce qu'il envoie. Sans effet pour un destinataire francophone.

      Le code de reprise doit être changé
      
        
      
          Le code de reprise livré avec l'application est public : il est écrit
          dans le code source, que tout le monde peut lire. Il permet de changer le mot de passe
          du responsable, ou de supprimer son compte — donc de reprendre le registre.
        
      
        
      
          En attendant, la reprise n'est acceptée que depuis ce poste, celui qui
          garde le registre. Les autres postes du bureau se voient refuser l'accès. C'est une
          protection de secours, pas une solution : choisissez un code propre au bureau.
        
      
        
      
          Sur le poste qui tient le registre, ouvrez le fichier de démarrage et donnez une valeur
          à MASTER_CODE, puis redémarrez l'application. Notez ce code sur papier et
          rangez-le : personne ne peut le retrouver s'il est perdu — il n'est conservé que
          sous forme d'empreinte.

      Accès des agents (0)
      
          
      
            
          
      
        
      
        
      
          Un agent ouvre l'application sur n'importe quel poste avec un identifiant et un
          code à six chiffres — sans courriel ni mot de passe. Vous décidez de ce qu'il voit :
          par défaut, il tient le guichet et remet le courrier, sans voir les codes de
          retrait ni pouvoir modifier le registre.
        
      
        
      
          
          
          
      
            
            
            
      Limité à une antenne, cet accès ne reçoit rien des autres.
      
          
      
          
      
          
      
            
            
          
      
        
      
        
      
        
      
      
      
    
      

    
      
      
      
        
      Où le registre est conservé
      
        
      
          
          
        
      
        
      
      
      
      
      
        
      Sauvegarde du registre
      
        
      
          Tout le registre tient dans un seul fichier. Une copie datée est conservée
          automatiquement sur le serveur ; téléchargez-en une de temps en temps et
          rangez-la ailleurs que sur ce poste.
        
      
        
      
          
          
          
        
      
        
      
        
      

        
      Durée de conservation
      
        
      
          Au-delà de cette durée, les courriers déjà retirés ou classés sont effacés
          du registre. Ceux qui attendent encore ne sont jamais touchés, quel que soit leur âge.
          Garder tout indéfiniment expose bien plus qu'il ne faudrait le jour d'une fuite.

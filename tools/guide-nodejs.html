Activer Node.js sur un PC Windows

Bureau du Courrier — guide en 5 étapes

Node.js, c'est quoi ?

C'est le moteur qui fait tourner le Bureau du Courrier sur votre poste. Une seule installation, une fois pour toutes — puis l'application démarre d'un double-clic.

Comptez une dizaine de minutes.

Étape 1 sur 5

Télécharger

Ouvrez nodejs.org/fr dans votre navigateur.

Prenez la version marquée LTS — c'est la version stable, recommandée pour un poste de travail.

Le fichier arrive dans votre dossier Téléchargements.

nodejs.org/fr
Télécharger Node.js (LTS)Windows Installer (.msi)
Étape 2 sur 5

Installer

Double-cliquez le fichier téléchargé.

Acceptez les options proposées : Suivant, puis Installer. Il n'y a rien à décocher.

Windows peut demander une confirmation d'administrateur : acceptez.

Étape 3 sur 5

Vérifier

Menu Démarrer → tapez powershell → ouvrez Windows PowerShell.

Tapez la commande, puis Entrée. Un numéro de version doit s'afficher : c'est la preuve que Node.js est actif.

Si rien ne s'affiche, redémarrez le PC : l'installation n'est prise en compte qu'au démarrage suivant.

Windows PowerShell
PS C:\Users\Accueil>
v22.11.0
PS C:\Users\Accueil>
10.9.0
✓ Node.js est actif
Étape 4 sur 5

Préparer l'application

Ouvrez le dossier bureau-du-courrier dans l'Explorateur.

Cliquez dans la barre d'adresse, tapez powershell, Entrée. Puis lancez l'installation des modules.

À faire une seule fois. C'est ce qui permet l'envoi automatique des courriels.

PowerShell — bureau-du-courrier
PS ...\bureau-du-courrier>
added 1 package in 3s
✓ Modules installés
Facultatif — copier le fichier de configuration :
PS ...>
Étape 5 sur 5

Démarrer

Double-cliquez demarrer.cmd dans le dossier.

Une fenêtre noire s'ouvre — c'est normal, c'est le serveur. Le navigateur s'ouvre tout seul sur l'application.

Laissez la fenêtre ouverte tant que vous utilisez l'application ; fermez-la pour arrêter.

demarrer.cmd
Bureau du Courrier v1.0.0
  interface   http://localhost:3000
  registre    data\db.json
  courriel    SMTP smtp.gmail.com:587
✓ Le navigateur s'ouvre…

C'est prêt.

Les fois suivantes, un seul geste : double-cliquer demarrer.cmd.
